📌 Project Title

Nepali News Category Classification using Machine Learning / Deep Learning

📖 Project Description

This project focuses on automatically classifying Nepali news articles into predefined categories using Natural Language Processing (NLP) and Machine Learning techniques.



🗂️ News Categories

The model classifies news into the following categories:

ArthaBanijya (Economy & Business)

Bichar (Opinion)

Desh (National)

Khelkud (Sports)

Manoranjan (Entertainment)

Prabas (Foreign Employment / Diaspora)

Sahitya (Literature)

SuchanaPrabidhi (Information Technology)

Swasthya (Health)

Viswa (International)


⚙️ Technologies Used

Programming Language: Python

Libraries & Frameworks:

pandas

scikit-learn
